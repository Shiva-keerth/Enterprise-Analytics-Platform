A powerful, dual-module enterprise analytics dashboard built with Streamlit. This platform unifies two critical business intelligence domains—**Financial Fraud Detection** and **Social Media Analytics**—into a single, highly interactive, and visually stunning web application.

---

## 🚀 Core Modules

### 1️⃣ Fraud Detection Engine
Designed for financial risk teams, this module ingests transaction datasets and provides deep exploratory data analysis (EDA) to identify anomalous patterns.
*   **Transaction Profiling:** Instantly view correlations between transaction amounts, time-of-day, and geographical locations.
*   **Risk Scoring Models:** Visualizations highlighting high-risk transaction clusters and potential synthetic identity fraud.
*   **Real-time Filtering:** Drill down into specific account segments using interactive data tables.

### 2️⃣ Social Media Analytics Engine
Designed for marketing and brand intelligence teams to track sentiment, engagement, and reach.
*   **Sentiment Analysis Trends:** Track positive, negative, and neutral brand mentions over time.
*   **Engagement Metrics:** Visualize KPIs like virality rate, click-through rates (CTR), and demographic reach.
*   **Content Performance:** Identify which content formats (Video, Image, Text) drive the highest ROI.

## 🎨 UI / UX Design
This dashboard is engineered with a premium **Dark Mode Glassmorphism** aesthetic:
*   Deep space gradient backgrounds (`#0a1128` to `#162244`).
*   Neon cyan (`#00ffb4`) metric values with translucent, glowing KPI cards.
*   Responsive layout optimized for wide-screen data visualization.

---

## 🛠️ Technology Stack
*   **Frontend / UI:** Streamlit
*   **Data Processing:** Pandas, NumPy
*   **Architecture:** Modular design separating data ingestion (`utils.data_pipeline`), fraud logic (`modules.fraud_engine`), and social logic (`modules.social_engine`).

## 💻 Local Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shiva-keerth/Enterprise_Analytics_Platform.git
   cd Enterprise_Analytics_Platform
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the application:**
   ```bash
   streamlit run app.py
   ```
