# 🏢 Enterprise Analytics Platform

A unified data engineering and analytics dashboard combining **Financial Fraud Detection** and **Social Media Performance** into a single glassmorphism UI.

## Features
- **Data Engineering Layer**: Simulates ETL pipelines with caching and missing-data handling.
- **Fraud Engine**: Analyzes synthetic financial transactions to identify risk patterns.
- **Social Engine**: Evaluates content engagement, reach, and follower correlation.

## Tech Stack
- Python, Streamlit, Pandas, Matplotlib

## How to Run
```bash
pip install streamlit pandas matplotlib
streamlit run app.py
```
